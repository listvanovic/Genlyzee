## English

STAR is an external aligner ([alexdobin/STAR](https://github.com/alexdobin/STAR))
used in this project solely as a reference solution for validating the
own implementation in `genome_index/`. It is not part of the work, has
not been reimplemented, and is not modified beyond the fix needed to
build it on macOS.

This document describes only building and running STAR, and the
comparison procedure. A description of the own algorithms is in the
[main README](../README.md), and the full comparison report (both
scopes, chromosome 2L and the whole genome) is in
[`../REPORT.md`](../REPORT.md).

### Prerequisites

A Unix shell, `git`, `make`, and a C++ compiler. On macOS, `libomp` is
additionally required, which STAR uses for parallel execution:

```bash
brew install libomp
```

### Input data

The pipeline expects, relative to the repository root:

```text
Fly/Drosophila_melanogaster.BDGP6.dna.toplevel.fa
Fly/IFM48h_1.fastq
```

The `Fly/` directory is not included in the repository. A GTF annotation
file that may also be present in it is not used in any step.

### Pipeline steps

Run every command below from the repository root.

#### 1. Building STAR

```bash
./star_comparison/scripts/build_star_macos.sh
```

Clones STAR at tag `2.7.11b` into `star_comparison/build/`, applies
`star_comparison/patches/star_2.7.11b_macos_libcxx_fix.patch`, and builds
the binary at `star_comparison/bin/STAR`. The fix is required on macOS,
for the reasons described [below](#note-on-star-on-macos).

On Linux, a standard build following STAR's own instructions is expected
to work without the fix, but this has not been verified in this
repository.

#### 2. Running STAR

```bash
./star_comparison/scripts/run_star.sh
```

Builds the genome index, if one does not already exist, and runs
alignment:

```text
STAR --runMode genomeGenerate --runThreadN 6 \
  --genomeDir star_comparison/index \
  --genomeFastaFiles Fly/Drosophila_melanogaster.BDGP6.dna.toplevel.fa \
  --genomeSAindexNbases 12 --genomeChrBinNbits 16

STAR --runMode alignReads --runThreadN 6 \
  --genomeDir star_comparison/index \
  --readFilesIn Fly/IFM48h_1.fastq \
  --outSAMtype SAM \
  --outFileNamePrefix star_comparison/results/star/IFM48h_1.
```

The `--genomeSAindexNbases 12` and `--genomeChrBinNbits 16` parameters
are reduced below the default values, as STAR's manual recommends for
small and fragmented genomes. The *Drosophila melanogaster* genome has
about 144 million bases spread across 1870 records, most of them short
scaffolds.

The thread count can be changed with the `THREADS` environment variable.

Results are written to `star_comparison/results/star/`:

| File | Content |
|---|---|
| `IFM48h_1.Aligned.out.sam` | alignments in SAM format |
| `IFM48h_1.Log.final.out` | alignment summary generated by STAR itself |
| `genome_generate_time_mem.log` | time and memory for the index build |
| `star_alignment_time_mem.log` | time and memory for alignment |

Time and memory are measured with `/usr/bin/time -l`. The full SAM output
is not in the repository due to size; the sample
`IFM48h_1.Aligned.out.sample.sam` is included alongside it.

#### 3. Selecting reads suitable for comparison

```bash
python3 star_comparison/scripts/filter_clean_reads.py \
  star_comparison/results/star/IFM48h_1.Aligned.out.sam \
  star_comparison/results/filtered/clean_reads.tsv
```

Keeps reads by the [criterion below](#read-selection-criterion) and
writes out `read_id`, sequence, chromosome, and position.

#### 4. Aligning the same reads with the own aligner

```bash
python3 star_comparison/scripts/make_fasta_input.py \
  star_comparison/results/filtered/clean_reads.tsv \
  star_comparison/results/my_aligner/clean_reads_input.fasta

mkdir -p star_comparison/my_index
python3 star_comparison/scripts/build_my_index.py

python3 star_comparison/scripts/run_my_aligner.py \
  star_comparison/results/my_aligner/clean_reads_input.fasta \
  star_comparison/results/my_aligner/my_alignments.tsv \
  --max-mismatches 3
```

`build_my_index.py` merges every contig of the reference genome into one
string, with 200 `N` bases separating them so a read cannot align across
a contig boundary, and builds a single suffix array over it. The script
does not create the destination directory itself, hence the `mkdir -p`
above.

`run_my_aligner.py` then aligns the reads against that index and
classifies each one as `unique`, `multi`, or `unmapped`.

This step uses the whole-genome index and thereby differs from
`run_pipeline.py` at the repository root, which operates over a single
chromosome. Both use the same code from `genome_index/`.

#### 5. Comparing coordinates

```bash
python3 star_comparison/scripts/compare_coordinates.py \
  star_comparison/results/filtered/clean_reads.tsv \
  star_comparison/results/my_aligner/my_alignments.tsv \
  star_comparison/results/comparison/comparison.csv \
  --mismatches-out star_comparison/results/comparison/mismatches.csv \
  --tolerance 0
```

For every read, checks whether the chromosome and position match, within
the given tolerance. Disagreements are written out separately.

```bash
python3 star_comparison/scripts/inspect_mismatches.py \
  star_comparison/results/comparison/mismatches.csv \
  star_comparison/results/filtered/clean_reads.tsv \
  star_comparison/results/comparison/mismatches_verified.csv
```

For every disagreement, counts the actual mismatches against the
reference at both reported positions, instead of assuming STAR's
position is correct by default.

```bash
python3 star_comparison/scripts/extract_nh.py \
  star_comparison/results/star/IFM48h_1.Aligned.out.sam \
  star_comparison/results/filtered/clean_reads_nh.tsv
```

Extracts STAR's `NH` tag, i.e. the number of loci STAR itself reported
for that read. Used to split the comparison by whether STAR itself was
confident about the read's placement.

### Read-selection criterion

STAR handles splicing, insertions, deletions, and clipping, while the own
aligner performs only ungapped, mismatch-tolerant alignment. The
comparison is therefore restricted to reads STAR itself aligned without
those operations:

- a primary, mapped alignment: `FLAG` does not contain `0x4`, `0x100`, or
  `0x800`,
- a CIGAR of the form `^(\d+)M$`, with the number equal to the read
  length.

`M` means alignment without a shift, not a perfect match; individual
bases can still be mismatched. Any `S`, `H`, `I`, `D`, or `N` operation
excludes the read from the comparison. A detailed description of the SAM
format is in
[`../REPORT.md`](../REPORT.md#shared-criteria-sam-fields-and-the-cigar-string).

Reads are not simulated, so the true origin of any given read is not
known. STAR is used as a reference, not as an absolutely correct
solution, and results are expressed as concordance with STAR.

### Comparison over a single chromosome

To compare the output of `run_pipeline.py`, which operates over a single
chromosome, a separate script is used that does the filtering and the
comparison in one pass:

```bash
python3 star_comparison/scripts/compare_chromosome.py \
  star_comparison/results/star/IFM48h_1.Aligned.out.sam \
  results/chr2L/my_alignments_full.tsv \
  2L results/chr2L/comparison_chr2L.csv --tolerance 0
```

The arguments are, in order, STAR's SAM output, the own pipeline's TSV
output, the chromosome name, and the destination file. Results are in
[`../REPORT.md`](../REPORT.md#results-on-chromosome-2l).

### Note on STAR on macOS

On the configuration used in this work (STAR 2.7.11b from the Homebrew
`rna-star` package, macOS 26.5, Apple Silicon, Apple clang 15.0.0 with
libc++), alignment silently reports zero processed reads, with exit
status 0.

The cause is STAR relying on `std::stringbuf::pubsetbuf()` making the
given buffer the stream's actual internal storage. The C++ standard
leaves this to the implementation, and libc++ treats the call as a no-op,
so the buffers stay empty.

The fix in `patches/star_2.7.11b_macos_libcxx_fix.patch` replaces that
call with an explicit copy via `std::stringbuf::str()`. The finding has
not been checked on other versions of macOS or STAR, and the fix has not
been tested on Linux.

Unix ljuska, `git`, `make` i C++ kompajler. Na macOS-u je dodatno potreban

### Ulazni podatci

Pipeline očekuje, relativno na korijenski direktorij repozitorija:

```text
Fly/Drosophila_melanogaster.BDGP6.dna.toplevel.fa
Fly/IFM48h_1.fastq
```

Direktorij `Fly/` nije uključen u repozitorij. Datoteka s anotacijama u GTF
formatu koja se u njemu može nalaziti ne koristi se ni u jednom koraku.

### Koraci pipelinea

Sve naredbe pokreću se iz korijenskog direktorija repozitorija.

#### 1. Izgradnja STAR-a

```bash
./star_comparison/scripts/build_star_macos.sh
```

Klonira STAR na oznaci `2.7.11b` u `star_comparison/build/`, primjenjuje
`star_comparison/patches/star_2.7.11b_macos_libcxx_fix.patch` i gradi
binarnu datoteku `star_comparison/bin/STAR`. Popravak je nužan na macOS-u,
iz razloga opisanih [niže](#napomena-o-star-u-na-macos-u).

Na Linuxu se očekuje da radi uobičajena izgradnja prema uputama STAR-a, bez
popravka, ali to nije provjereno u ovom repozitoriju.

#### 2. Pokretanje STAR-a

```bash
./star_comparison/scripts/run_star.sh
```

Gradi genomski indeks, ako već ne postoji, i pokreće poravnanje:

```text
STAR --runMode genomeGenerate --runThreadN 6 \
  --genomeDir star_comparison/index \
  --genomeFastaFiles Fly/Drosophila_melanogaster.BDGP6.dna.toplevel.fa \
  --genomeSAindexNbases 12 --genomeChrBinNbits 16

STAR --runMode alignReads --runThreadN 6 \
  --genomeDir star_comparison/index \
  --readFilesIn Fly/IFM48h_1.fastq \
  --outSAMtype SAM \
  --outFileNamePrefix star_comparison/results/star/IFM48h_1.
```

Parametri `--genomeSAindexNbases 12` i `--genomeChrBinNbits 16` smanjeni su
ispod zadanih vrijednosti, kako priručnik STAR-a preporučuje za male i
fragmentirane genome. Genom *Drosophila melanogaster* ima približno 144
milijuna baza raspoređenih u 1870 zapisa, od kojih je većina kratkih
scaffolda.

Broj dretvi može se promijeniti varijablom okoline `THREADS`.

Rezultati se zapisuju u `star_comparison/results/star/`:

| Datoteka | Sadržaj |
|---|---|
| `IFM48h_1.Aligned.out.sam` | poravnanja u SAM formatu |
| `IFM48h_1.Log.final.out` | sažetak poravnanja koji STAR sam generira |
| `genome_generate_time_mem.log` | vrijeme i memorija izgradnje indeksa |
| `star_alignment_time_mem.log` | vrijeme i memorija poravnanja |

Vrijeme i memorija mjere se alatom `/usr/bin/time -l`. Puni SAM izlaz nije
u repozitoriju zbog veličine; uz njega se nalazi uzorak
`IFM48h_1.Aligned.out.sample.sam`.

#### 3. Odabir readova prikladnih za usporedbu

```bash
python3 star_comparison/scripts/filter_clean_reads.py \
  star_comparison/results/star/IFM48h_1.Aligned.out.sam \
  star_comparison/results/filtered/clean_reads.tsv
```

Zadržava readove prema [kriteriju niže](#kriterij-odabira-readova) i
zapisuje `read_id`, sekvencu, kromosom i poziciju.

#### 4. Poravnanje istih readova vlastitim alignerom

```bash
python3 star_comparison/scripts/make_fasta_input.py \
  star_comparison/results/filtered/clean_reads.tsv \
  star_comparison/results/my_aligner/clean_reads_input.fasta

mkdir -p star_comparison/my_index
python3 star_comparison/scripts/build_my_index.py

python3 star_comparison/scripts/run_my_aligner.py \
  star_comparison/results/my_aligner/clean_reads_input.fasta \
  star_comparison/results/my_aligner/my_alignments.tsv \
  --max-mismatches 3
```

`build_my_index.py` spaja sve kontige referentnog genoma u jedan niz, uz
odvajanje s po 200 baza `N` kako se read ne bi mogao poravnati preko
granice kontiga, i gradi jedan suffix array nad njim. Skripta ne stvara
odredišni direktorij, pa je potreban `mkdir -p`.

`run_my_aligner.py` poravnava readove nad tim indeksom i klasificira ih kao
`unique`, `multi` ili `unmapped`.

Ovaj korak koristi indeks cijelog genoma i time se razlikuje od
`run_pipeline.py` u korijenskom direktoriju, koji radi nad jednim
kromosomom. Oba koriste isti kod iz `genome_index/`.

#### 5. Usporedba koordinata

```bash
python3 star_comparison/scripts/compare_coordinates.py \
  star_comparison/results/filtered/clean_reads.tsv \
  star_comparison/results/my_aligner/my_alignments.tsv \
  star_comparison/results/comparison/comparison.csv \
  --mismatches-out star_comparison/results/comparison/mismatches.csv \
  --tolerance 0
```

Za svaki read provjerava podudaraju li se kromosom i pozicija, unutar
zadane tolerancije. Neslaganja se zapisuju zasebno.

```bash
python3 star_comparison/scripts/inspect_mismatches.py \
  star_comparison/results/comparison/mismatches.csv \
  star_comparison/results/filtered/clean_reads.tsv \
  star_comparison/results/comparison/mismatches_verified.csv
```

Za svako neslaganje broji stvarna nepodudaranja naspram reference na obje
prijavljene pozicije, umjesto da se STAR-ova pozicija unaprijed uzme kao
ispravna.

```bash
python3 star_comparison/scripts/extract_nh.py \
  star_comparison/results/star/IFM48h_1.Aligned.out.sam \
  star_comparison/results/filtered/clean_reads_nh.tsv
```

Izdvaja STAR-ovu oznaku `NH`, odnosno broj lokusa koje je STAR sam prijavio
za pojedini read. Koristi se za podjelu usporedbe prema tome je li STAR bio
siguran u smještaj reada.

### Kriterij odabira readova

STAR obrađuje splicing, insercije, delecije i clipping, dok vlastiti
aligner izvodi isključivo neprekinuto poravnanje s dopuštenim
nepodudaranjima. Usporedba je stoga ograničena na readove koje je i sam
STAR poravnao bez tih operacija:

- primarno, mapirano poravnanje: `FLAG` ne sadrži `0x4`, `0x100` ni `0x800`,
- CIGAR oblika `^(\d+)M$`, pri čemu je broj jednak duljini reada.

Oznaka `M` znači poravnanje bez pomaka, a ne savršeno podudaranje;
pojedinačne baze i dalje mogu biti nepodudarne. Bilo koja operacija `S`,
`H`, `I`, `D` ili `N` isključuje read iz usporedbe. Detaljan opis SAM
formata nalazi se u
[`../REPORT.md`](../REPORT.md#zajednički-kriteriji-sam-polja-i-cigar-string).

Readovi nisu simulirani, pa stvarno podrijetlo pojedinog reada nije
poznato. STAR se koristi kao referentno, a ne kao apsolutno točno rješenje,
i rezultati se izražavaju kao podudarnost sa STAR-om.

### Usporedba nad jednim kromosomom

Za usporedbu izlaza programa `run_pipeline.py`, koji radi nad jednim
kromosomom, koristi se zasebna skripta koja filtriranje i usporedbu izvodi
u jednom prolasku:

```bash
python3 star_comparison/scripts/compare_chromosome.py \
  star_comparison/results/star/IFM48h_1.Aligned.out.sam \
  results/chr2L/my_alignments_full.tsv \
  2L results/chr2L/comparison_chr2L.csv --tolerance 0
```

Argumenti su, redom, SAM izlaz STAR-a, TSV izlaz vlastitog pipelinea, naziv
kromosoma i odredišna datoteka. Rezultati su u
[`../REPORT.md`](../REPORT.md#rezultati-na-kromosomu-2l).

### Napomena o STAR-u na macOS-u

Na konfiguraciji korištenoj u ovom radu (STAR 2.7.11b iz Homebrew paketa
`rna-star`, macOS 26.5, Apple Silicon, Apple clang 15.0.0 uz libc++)
poravnanje tiho prijavljuje nula obrađenih readova, uz izlazni status 0.

Uzrok je oslanjanje STAR-a na to da `std::stringbuf::pubsetbuf()` predani
spremnik učini stvarnim internim spremištem toka. C++ standard to ostavlja
implementaciji, a libc++ taj poziv tretira kao praznu operaciju, pa
spremnici ostaju prazni.

Popravak u `patches/star_2.7.11b_macos_libcxx_fix.patch` zamjenjuje taj
poziv izričitim kopiranjem preko `std::stringbuf::str()`. Nalaz nije
provjeren na drugim verzijama macOS-a ni STAR-a, a popravak nije testiran
na Linuxu.
